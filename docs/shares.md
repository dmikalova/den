# File shares

den exports the array over SMB. Samba is in the host layer, not a container,
because a container that bind mounts the whole array in order to re-export it
is a container in name only.

## Reach

Shares are on the tailnet and nowhere else. Two things make that true, and
either one alone would do:

- `smbd` binds `lo` and `tailscale0`. It does not listen on the LAN interface.
- `ufw` denies inbound from the LAN except ssh and mDNS, and allows everything
  in on `tailscale0`.

SMB3 is the minimum protocol and encryption is required, so a session that
cannot encrypt does not connect. There is no guest access and no NetBIOS;
`nmbd` is masked.

| Share | Path | Notes |
| --- | --- | --- |
| `storage` | `/mnt/storage` | the pooled array; `timemachine` is vetoed here |
| `timemachine` | `/mnt/storage/timemachine` | 2 TB cap, 0700 |

## Connect

From macOS, `Go` → `Connect to Server`:

```
smb://den/storage
```

The user is `dmikalova`. The password is **not** the login password: Samba
keeps its own database. It is `SAMBA_PASSWORD` in the `den-host` secret,
generated by the infrastructure repo, and the Mac keychain should hold it
after the first connection.

For Time Machine, connect to `smb://den/timemachine` first, then pick it in
System Settings. The share advertises itself as a Time Machine target, so it
appears in the list once mounted.

## Password

`den-samba.service` writes the password into Samba's database on every boot,
from the credential systemd hands it. That is deliberate: a rebuilt host, or a
restored `/var/lib/samba`, comes back correct without anyone remembering that
it had to be set.

Rotating it means changing `random_password.samba` in the infrastructure repo,
which breaks every connected client until each one is told the new password.
The resource is marked `prevent_destroy` for that reason.

## Time Machine is not backed up

`/mnt/storage/timemachine` is excluded from kopia. It is already a backup, and
a sparsebundle rewrites bands on every run, so uploading it would cost more to
store than everything else on the host put together.

This means a Time Machine backup is protected by snapraid against a drive
dying, and by nothing against the building. That is the right trade for a copy
whose original is a laptop that leaves the house.
